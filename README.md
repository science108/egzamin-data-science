# egzamin-data-science

Materiały do egzaminu kwalifikacyjnego — Informatyka / Data Science (AGH).

## 🚀 Uruchom w przeglądarce

**[👉 Otwórz interaktywną aplikację do nauki](https://science108.github.io/egzamin-data-science/)**

## Zawartość

- `index.html` / `egzamin-agh.html` — główna aplikacja do nauki (pytania, fiszki, testy)
- `skrypt-egzamin.md` / `.docx` — skrypt z materiałem
- `testy-egzamin.md` / `.docx` — testy przykładowe
- `plan-nauki.md` / `.docx` — plan nauki
- `fiszki-egzamin.csv` — fiszki w CSV
- `eli5-egzamin.json` — wyjaśnienia „po ludzku"
- `krzyzowki-egzamin.json` — krzyżówki tematyczne
- `build_html.py`, `gen_fiszki.py`, `more_data.py`, `apply_more.py` — skrypty generujące

## Lokalnie

Wystarczy otworzyć `index.html` w przeglądarce — cała aplikacja jest samowystarczalna (HTML + inline CSS/JS).
